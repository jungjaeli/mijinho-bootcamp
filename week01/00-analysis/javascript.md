# JavaScript 5단계 분석

1. **개념 이해** — JavaScript로 값을 계산하고 조건에 따라 실행 흐름을 바꿀 수 있다.
2. **입력과 출력 정리** — 조건문 예제는 점수를 입력으로 사용하고 통과 여부를 출력한다.
3. **실행 흐름 설계** — 점수를 읽은 뒤 기준을 비교하고 두 결과 중 하나를 출력한다.
4. **코드 구현** — [조건문 예제](../part1-js/02-condition.js)의 `if...else`로 두 갈래를 표현한다.
5. **검증과 회고** — 점수가 59, 60, 61일 때 예상한 결과와 실제 출력을 비교한다. [예외 처리 예제](../part1-js/05-error-handling.js)에서는 잘못된 JSON과 필드가 빠진 JSON도 확인한다.

```text
시작 → 점수 확인 → 60점 이상인가?
                         ├─ 예 → 통과 출력 → 종료
                         └─ 아니요 → 재도전 출력 → 종료
```
